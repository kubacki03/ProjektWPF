ProjektWPF - osobisty asystent
ProjektWPF to prosta aplikacja asystenta, która ma pomagać w codziennych czynnościach

## Demo
https://youtu.be/RX7q7QCLsFM


## Funkcje
-Asystent głosowy bazujący na OPENAI API
-Kontrola stanu procesora i ramu
-Panel sterowania odtwarzacza spotify
-Tworzenie/edytowanie notatek
-Tworzenie listy wydatków
-Tworzenie listy ulubionych filmów, ocenianie ich i pobieranie danych o tych filmach z api
-Sprawdenie pogody na podstawie IP użytkownika
-Minutnik

## Technologie
-WPF
-OPENAI API
-SPOTIFY API
-SQL SERVER
-ENTITY FRAMEWORK

## Instalacja 
1) Sklonuj repozytorium
git clone https://github.com/kubacki03/ProjektWPF.git
2)Przejdz do katalogu z projektem
cd ProjektWPF
3)Skompiluj projekt
dotnet build
4)Uruchom projekt
dotnet run
